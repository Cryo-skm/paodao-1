# 上海大学之嘉定校区·跑刀

一个基于地图的校园论坛网站

---

## 🚀 快速部署指南（国内可用）

### 第1步：注册 Bmob（国内稳定可用）

1. 打开 https://www.bmobapp.com/ 注册账号
2. 登录后点击 **「创建应用」**，选择「开发版」（免费够用）
3. 应用名称随便写（比如 `shu-forum`），创建
4. 进入应用后，点击左侧 **「设置」→「应用密钥」**
5. 复制 **Application ID** 和 **REST API Key**

### 第2步：在 script.js 填入你的配置

1. 用记事本打开 `网站5/script.js`
2. 找到第 2-4 行，替换成你自己的：

```javascript
const BMOB_APP_ID = "你的 Application ID";
const BMOB_REST_KEY = "你的 REST API Key";
```

### 第3步：部署到公网（国内可用）

**推荐使用 Gitee Pages（国内访问快）：**

1. 注册 https://gitee.com/
2. 创建仓库 → 选「公开」
3. 进入仓库 → 点击「上传文件」
4. 把 `网站5` 文件夹里的所有文件拖进去
5. 点击「管理」→「Gitee Pages」→ 启动服务
6. 等 1 分钟，你的网站就上线了！

## 💡 常见问题

**Q: 页面打不开？**
A: 检查浏览器按 F12 看 Console 报错。大概率是 Bmob 配置没填对。

**Q: 登录/注册失败？**
A: 确认 Bmob 的用户认证已开启（默认开启）。

**Q: 如何让更多人用？**
A: 分享你的 Gitee Pages 链接就行！
